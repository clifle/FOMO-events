# BeYou in Town : Torino

A lightweight events guide for Torino, Italy.

## Publish

This site is deployed to GitHub Pages from the `main` branch using the workflow in `.github/workflows/pages.yml`.

## Event coverage

The page aggregates dated events from public organizer, venue, cultural institution, city and regional calendars, with public social posts where discoverable. Listings are a curated pilot and cannot guarantee exhaustive coverage. Verify dates, tickets, venue access and availability with event organizers.
